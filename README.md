# DELIVER ASSETS Prime

Sitio institucional e investor-facing de DELIVER ASSETS.

## Propósito

Este repositorio desarrolla una página pública independiente para comunicar la visión, el modelo operativo y la oportunidad de DELIVER ASSETS ante inversionistas y aliados.

## Principios

- No sustituye ni modifica el prototipo original `DELIVER-ASSETS`.
- La dirección visual oficial utiliza una composición 60/30/10: marfil, negro y amarillo.
- La primera versión es un sitio estático sin dependencias de producción.
- `main` representa la versión estable y publicable.
- El trabajo de diseño se desarrolla mediante ramas y pull requests.

## Estado

Repositorio inicializado. La implementación comienza en `design/investor-homepage`.

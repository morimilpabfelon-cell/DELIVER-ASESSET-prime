# Contribución

## Flujo obligatorio

1. Crear una rama desde `main`.
2. Mantener un objetivo por commit.
3. Revisar `git diff --check` antes de confirmar cambios.
4. No mezclar diseño, contenido y configuración de despliegue en un mismo commit.
5. Integrar mediante pull request.

## Reglas

- No introducir dependencias sin justificar su necesidad.
- No publicar cifras como reales sin fuente y fecha.
- No incorporar formularios que recojan datos sin backend y política de privacidad.
- No alterar el repositorio original `DELIVER-ASSETS` desde este proyecto.

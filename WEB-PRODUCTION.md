# DELIVER ASSETS — Web Production Foundation

Branch: `design/public-homepage`

## Purpose

Convert the approved editorial campaign language into a real public website built from semantic HTML, responsive CSS, SVG graphics and JavaScript interactions.

## Current implementation

- Original logo preserved as a versioned web asset.
- Responsive public homepage.
- Mobile navigation.
- Interactive tracking demonstration.
- Accessible FAQ accordion.
- Contact dialog with local validation.
- Reduced-motion support.
- CSS and SVG visual language instead of full-page poster images.
- Placeholder operational metrics clearly marked instead of invented production data.

## Deliberately not connected yet

- Tracking API.
- Coverage data source.
- Contact delivery channel.
- Authentication.
- Customer, Business, Rider and Control applications.
- CMS and analytics.

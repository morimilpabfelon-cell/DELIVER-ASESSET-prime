# Paridad de contenido con DELIVER-ASSETS

## Regla oficial

Prime conserva la arquitectura pública, mensajes y narrativa de `DELIVER-ASSETS`. El cambio es visual y de presentación, no de producto.

## Estructura preservada

1. Hero y propuesta principal.
2. Manifiesto de producto.
3. Categorías: comida, mercado, farmacia y envíos.
4. Experiencia interactiva de pedido.
5. Proceso: PIDE / MIRA / RECIBE.
6. Propuesta para negocios.
7. Propuesta para repartidores.
8. Cobertura, seguridad, ayuda y estado.
9. Registro conceptual de primera etapa.
10. Acceso al ecosistema de cuatro roles.

## Mensajes preservados

- `PIDE LO QUE QUIERAS. MUÉVELO SIN VUELTAS.`
- `NO ES SOLO ENTREGAR. ES MOVER LA CIUDAD.`
- `TODO CABE EN EL MISMO RECORRIDO.`
- `ARMA UN PEDIDO.`
- `TRES PASOS. CERO RUIDO.`
- `VENDE MÁS. OPERA MEJOR.`
- `MUÉVETE. ENTREGA. AVANZA.`
- `MÁS QUE UNA APP. UN SISTEMA.`
- `ENTRA ANTES QUE TODOS.`

## Cambios permitidos

- Diseño 60/30/10.
- Composición, espaciado, tipografía y responsive.
- Ilustraciones y activos visuales.
- Adaptación técnica de React a HTML, CSS y JavaScript estático para GitHub Pages.
- Mejoras de accesibilidad y validación.

## Cambios prohibidos

- Sustituir la portada por un pitch institucional diferente.
- Inventar tracción, ingresos o resultados.
- Eliminar mensajes fundamentales del producto.
- Importar la autenticación simulada o datos personales del prototipo.

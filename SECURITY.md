# Política de seguridad

Este repositorio contiene un sitio estático institucional. No debe procesar credenciales, pagos, ubicaciones en tiempo real ni datos personales.

## Reporte

Los hallazgos de seguridad deben documentarse de forma privada antes de su publicación. No incluyas secretos, datos personales ni credenciales en issues públicos.

## Alcance actual

- HTML, CSS y JavaScript estático.
- GitHub Pages como canal de publicación.
- Sin backend ni API propia.
